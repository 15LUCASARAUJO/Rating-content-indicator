## About
The **Rating Content Indicator** was developed to optimize the collection of information from companies regarding user reviews, categorizing them into satisfaction levels. The goal is to provide quick and actionable insights into customer feedback.

---

## Features
- [ ] **Review Analysis:** Generates detailed review analysis documents, facilitating the understanding of user feedback.
- [ ] **AI Integration:** An Artificial Intelligence agent collects, categorizes, and autonomously sends review information.
- [ ] **Adaptive Interface:** Theme and accessibility focused on productivity, with a clean and responsive interface for different devices.

## Installation
To set up and run the project locally, follow the steps below:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/15LUCASARAUJO/Rating-content-indicator.git
    cd Rating-content-indicator
    ```

2.  **Create and activate a virtual environment (venv):**

    *   **Windows:**
        ```bash
        python -m venv venv
        .\venv\Scripts\activate
        ```

    *   **macOS/Linux:**
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *Ensure that the `requirements.txt` file exists in the project\'s root directory with all dependencies listed.*
