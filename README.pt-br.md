## Sobre
O **Indicador de Teor de Avaliações** foi desenvolvido para otimizar a coleta de informações de empresas referentes a avaliações de usuários, categorizando-as em níveis de satisfação. O objetivo é fornecer insights rápidos e acionáveis sobre o feedback dos clientes.

---

## Funcionalidades
- [ ] **Análise de Avaliações:** Gera documentos detalhados de análise de avaliações, facilitando a compreensão do feedback dos usuários.
- [ ] **Integração com IA:** Um agente de Inteligência Artificial coleta, categoriza e envia as informações de avaliações de forma autônoma.
- [ ] **Interface Adaptável:** Tema e acessibilidade focados em produtividade, com uma interface limpa e responsiva para diferentes dispositivos.

## Instalação
Para configurar e executar o projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/15LUCASARAUJO/Rating-content-indicator.git
    cd Rating-content-indicator
    ```

2.  **Crie e ative um ambiente virtual (venv):**

    *   **Windows:**
        ```bash
        python -m venv venv
        .\venv\Scripts\activate
        ```

    *   **macOS/Linux:**
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```

3.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```
    *Certifique-se de que o arquivo `requirements.txt` existe no diretório raiz do projeto com todas as dependências listadas.*
